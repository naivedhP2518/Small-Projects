A curated, professional showcase of web development projects, ranging from e-commerce solutions to productivity utilities. This portal serves as a unified entry point for exploring the digital craft of **Naivedh Patel**.

## ✨ Features

- **Premium UI/UX**: Clean white-theme design with high-quality typography.
- **Interactive Showcase**: Dynamic project grid with smooth hover states and glassmorphism effects.
- **Smooth Animations**: Powered by **GSAP** and **ScrollTrigger** for sophisticated reveal effects.
- **Responsive Layout**: Seamless experience across Mobile, Tablet, and Desktop.
- **Unified Portal**: Quick access to 11+ distinct web applications.

## 🛠️ Technology Stack

- **Core**: HTML5, Vanilla JavaScript
- **Styling**: Vanilla CSS (Custom properties, Grid, Flexbox)
- **Icons**: [Lucide Icons](https://lucide.dev/)
- **Animations**: [GSAP](https://greensock.com/gsap/) (GreenSock Animation Platform)
- **Fonts**: Inter & Outfit (via Google Fonts)
